## 基本模式

- 定電流 CC、定電阻 CR、定電壓 CV、定功率 CP
- 動態：動態定電流 CCD、動態定電阻 CRD、CRCC、CVCC、Auto(CC、CV、CR、CP四種混合)
- max loading：6 kW
- min rise time：20 µs
- **上電前先上 loading(PSU用CC抽載)**

## 型號解讀

## 63224A 設定項目

- Von_POT：起始拉載電壓設定
- Von_latch：起始拉載電壓鎖定（電壓超過 Von 後開始持續拉載，即使電壓掉到Von以下）
- Von_Voff：卸載電壓設定
- Remote：GPIB / Ethernet / Digital I/O / CAN（CAN BUS）
- Short_Key：
  - Disable
  - HOLD：持續按 SHORT 才 short
  - TOGGLE：按一下 SHORT，持續 work
- Window_Time：0.02~6s，default 0.02 s，可調整的量測平均時間

## CC mode：定電流

- L1：__ A，SR ↗（rise slew rate）
- L2：__ A，SR ↘（fall slew rate）
- （按 A/B 鍵在 state A、state B 間切換，上升／下降斜率分別由 rise / fall slew rate 決定）

## 其他模式

- CR：同 CC 概念，設 A/B state，可手動切換
- CV：多 I_LIMIT，usually 設 1.1 倍 I_UUT max
  - Response：E-load 電壓反應速度，共四檔 UD / FAST / NORMAL / SLOW
  - I_RANGE：電流量測檔位 H / M / L（解析度）
- CP：多 V_range，電壓量測檔位 H / M / L（解析度）
  - server 多用，e.g. GPU
  - good at：BBU discharge、Vin drop、hold-up time
- CCD：loading 依編程之電流值及動態時序進行動態電流拉載
  - T1、T2：L1 和 L2 拉載時間
  - Repeat：0 = infinity loop
- CRD：電阻值 Dynamic

## Advance

1. **BATT**（電池放電測試的 Timer 功能）：測電池放電到 E_END 截止電壓的時間
2. **SWD**（正弦波動態電流拉載 Sine Wave Dynamic）
   - I_DC：直流偏壓電流 loading
   - I_AC：交流 Ipp loading
   - FREQ：頻率拉載 0~20 kHz
3. **SWP**（動態負載頻率掃描模式 CC Dynamic Sweep）：loading 提供一個獨特的定電流動態頻率掃描，以變頻找出 worst UUT's voltage（CC mode）
   - FSTART：起始 freq，0.01~50 kHz
   - FEND：終止 freq
   - FSTEP：步階 freq
   - DWELL：1 個 STEP 的 Duration
4. **OCP & OPP**
5. **CZ**：（手繪等效電路：V_s 串 L_s、R_s，負載端 C_L 並聯 R_L）
6. **UDW**：使用者自訂波形
7. **MPPT**：最大功率追蹤（手繪 P–V 曲線，頂點 ΔP/ΔV = 0）

## 複合模式

- **CVCC**：模擬電源在實際使用上會遇到的負載行為
  - V_SET：CV 區要鎖定的電壓值
  - I_SET：CC 區要鎖定的電流值，也是 CV → CC 轉換的電流門檻
- **CRCC**：定電阻及定電流
  - 用 CC mode 測開機時，電壓還在 0 V 附近 loading 就要求抽滿額定電流，PSU 可能誤判 short or overload
  - 用 CR mode 測開機時，V 低，I 也低
  - R_SET 用滿載算：ex. 12 V / 50 A，R = 12 / 50 = 0.24 Ω
  - I_SET 避免 OCP：I_SET < OCP 點
- **CVCR**：（少用）
- **Auto Mode**：依電壓由低到高 CV → CR → CC → CP

## Program

- 10 組 program、255 組 sequence；program 之間可以 link（program1 → program2 → program3，各自program含 seq1、seq2…）
- TYPE：LIST
- REPEAT：0 = infinity
- NEXT：SET_SEQ
  - SKIP：跳過 seq
  - AUTO：Dwell 時間過後 loading 跳下一 seq
  - MANUAL：手動切 seq（ENTER）
  - External：用外部 signal TRIG_SEQ
